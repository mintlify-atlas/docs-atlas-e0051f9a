Alert is an inline feedback container that stays visible until the user acts — making it the right choice for authentication failures, form validation summaries, permission warnings, and configuration notices. It composes four sub-components (`Alert`, `AlertTitle`, `AlertDescription`, `AlertAction`) and pairs naturally with any Lucide icon to reinforce the semantic meaning of the message.

## Installation

<CodeGroup>
```bash CLI
npx baseui-cn add alert
```

```bash Manual
# No extra dependencies required
# Copy the component source into components/ui/alert.tsx
```
</CodeGroup>

## Usage

```tsx
import { Alert, AlertAction, AlertDescription, AlertTitle } from "@/components/ui/alert"
import { Info } from "lucide-react"
```

```tsx
<Alert>
  <Info className="size-4 text-info" />
  <AlertTitle>Heads up</AlertTitle>
  <AlertDescription>
    This alert stays inline with your form or settings surface.
  </AlertDescription>
</Alert>
```

## Examples

### Variants

Five semantic variants map directly to common feedback scenarios.

```tsx
import {
  AlertCircle,
  AlertTriangle,
  CheckCircle2,
  Info,
  MessageSquare,
} from "lucide-react"
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert"

export function AlertVariants() {
  return (
    <div className="flex flex-col gap-3">
      <Alert variant="default">
        <MessageSquare className="size-4" />
        <AlertTitle>Note</AlertTitle>
        <AlertDescription>This is a default informational alert.</AlertDescription>
      </Alert>

      <Alert variant="info">
        <Info className="size-4 text-info" />
        <AlertTitle>Information</AlertTitle>
        <AlertDescription>Your session will expire in 10 minutes.</AlertDescription>
      </Alert>

      <Alert variant="success">
        <CheckCircle2 className="size-4 text-success" />
        <AlertTitle>Success</AlertTitle>
        <AlertDescription>Your changes have been saved successfully.</AlertDescription>
      </Alert>

      <Alert variant="warning">
        <AlertTriangle className="size-4 text-warning" />
        <AlertTitle>Warning</AlertTitle>
        <AlertDescription>This action may affect other users in your workspace.</AlertDescription>
      </Alert>

      <Alert variant="destructive">
        <AlertCircle className="size-4" />
        <AlertTitle>Error</AlertTitle>
        <AlertDescription>Invalid credentials. Please check your email and password.</AlertDescription>
      </Alert>
    </div>
  )
}
```

### Auth Failure

Use `variant="destructive"` on authentication forms to surface login errors inline.

```tsx
import { AlertCircle } from "lucide-react"
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert"
import { Button } from "@/components/ui/button"

export function AlertAuthFailure() {
  return (
    <div className="w-full max-w-sm space-y-4">
      <Alert variant="destructive">
        <AlertCircle className="size-4" />
        <AlertTitle>Sign-in failed</AlertTitle>
        <AlertDescription>
          The email or password you entered is incorrect. Please try again or reset your password.
        </AlertDescription>
      </Alert>
      <Button className="w-full">Try again</Button>
    </div>
  )
}
```

### With Action

Pair an alert with an action button for configuration or permissions messaging.

```tsx
import { AlertTriangle } from "lucide-react"
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert"
import { Button } from "@/components/ui/button"

export function AlertWithAction() {
  return (
    <Alert variant="warning">
      <AlertTriangle className="size-4 text-warning" />
      <AlertTitle>API key expiring soon</AlertTitle>
      <AlertDescription className="flex items-center justify-between gap-4">
        Your production API key expires in 3 days. Rotate it before it expires to avoid downtime.
        <Button size="sm" variant="outline">Rotate key</Button>
      </AlertDescription>
    </Alert>
  )
}
```

<Warning>
  Prefer `Alert` over toast notifications when the message must remain visible until the user resolves the issue — for example, a failed payment or a missing required configuration.
</Warning>

## Props

### Alert

| Prop      | Type                                                              | Default     | Description                                |
| --------- | ----------------------------------------------------------------- | ----------- | ------------------------------------------ |
| `variant` | `"default" \| "destructive" \| "info" \| "success" \| "warning"` | `"default"` | Color theme and semantic style of the alert |

### AlertTitle

A bold heading inside the alert. Accepts standard heading props.

### AlertDescription

Supporting text below the title. Accepts standard `div` props and can contain inline elements or action buttons.

### AlertAction

Optional trailing action slot rendered at the end of the alert row. Use it to place buttons or links alongside the message without nesting them inside `AlertDescription`.

Accepts standard `div` props.
