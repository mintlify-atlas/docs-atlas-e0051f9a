Card is a structured surface container that helps you organise related content into clearly defined regions. It composes seven sub-components — `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`, and `CardAction` — so you can mix and match sections without rigid slot constraints. Four variants control the visual treatment from filled to ghost, and three size options adjust the padding density.

## Installation

<CodeGroup>
```bash CLI
npx baseui-cn add card
```

```bash Manual
# No extra dependencies required
# Copy the component source into components/ui/card.tsx
```
</CodeGroup>

## Usage

```tsx
import {
  Card,
  CardHeader,
  CardFooter,
  CardTitle,
  CardAction,
  CardDescription,
  CardContent,
} from "@/components/ui/card"
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Card Content</p>
  </CardContent>
  <CardFooter>
    <p>Card Footer</p>
  </CardFooter>
</Card>
```

## Examples

### Basic Card

A simple card with a header section and body content.

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export function CardBasic() {
  return (
    <Card className="w-80">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>Last updated 3 days ago</CardDescription>
      </CardHeader>
      <CardContent>
        <p className="text-sm text-muted-foreground">
          This project contains the main application source, design tokens, and
          documentation for the design system.
        </p>
      </CardContent>
    </Card>
  )
}
```

### With Footer Actions

Use `CardFooter` for primary and secondary actions that relate to the card content.

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export function CardWithFooter() {
  return (
    <Card className="w-80">
      <CardHeader>
        <CardTitle>Delete account</CardTitle>
        <CardDescription>
          This action is permanent and cannot be undone.
        </CardDescription>
      </CardHeader>
      <CardContent>
        <p className="text-sm text-muted-foreground">
          All your data, workspaces, and integrations will be removed immediately.
        </p>
      </CardContent>
      <CardFooter className="gap-2">
        <Button variant="destructive">Delete account</Button>
        <Button variant="outline">Cancel</Button>
      </CardFooter>
    </Card>
  )
}
```

### With Header Action

Place a `CardAction` inside `CardHeader` to add a quick-access button or menu to the top-right corner.

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export function CardWithAction() {
  return (
    <Card className="w-80">
      <CardHeader>
        <CardTitle>Team Members</CardTitle>
        <CardDescription>5 members in this workspace</CardDescription>
        <CardAction>
          <Button size="sm" variant="outline">Invite</Button>
        </CardAction>
      </CardHeader>
      <CardContent>
        <p className="text-sm text-muted-foreground">
          Manage roles and permissions for each team member.
        </p>
      </CardContent>
    </Card>
  )
}
```

### Variants

Cards come in four visual variants to match different surface contexts.

```tsx
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"

export function CardVariants() {
  return (
    <div className="grid grid-cols-2 gap-4">
      <Card variant="default">
        <CardHeader><CardTitle>Default</CardTitle></CardHeader>
        <CardContent><p className="text-sm text-muted-foreground">Filled surface</p></CardContent>
      </Card>
      <Card variant="outline">
        <CardHeader><CardTitle>Outline</CardTitle></CardHeader>
        <CardContent><p className="text-sm text-muted-foreground">Border only</p></CardContent>
      </Card>
      <Card variant="elevated">
        <CardHeader><CardTitle>Elevated</CardTitle></CardHeader>
        <CardContent><p className="text-sm text-muted-foreground">Drop shadow</p></CardContent>
      </Card>
      <Card variant="ghost">
        <CardHeader><CardTitle>Ghost</CardTitle></CardHeader>
        <CardContent><p className="text-sm text-muted-foreground">No border or shadow</p></CardContent>
      </Card>
    </div>
  )
}
```

## Props

### Card

| Prop      | Type                                               | Default     | Description                                     |
| --------- | -------------------------------------------------- | ----------- | ----------------------------------------------- |
| `variant` | `"default" \| "outline" \| "elevated" \| "ghost"`  | `"default"` | Border and shadow treatment of the card surface |
| `size`    | `"default" \| "sm" \| "lg"`                        | `"default"` | Padding scale of the card                       |

### CardHeader

A flex container that arranges `CardTitle`, `CardDescription`, and `CardAction` in a two-column grid. Accepts standard `div` props.

### CardTitle

Renders a heading element for the card. Accepts standard heading props.

### CardDescription

Secondary text below the title, styled as muted foreground. Accepts standard `p` props.

### CardContent

Main body area of the card. Accepts standard `div` props.

### CardFooter

Flex row at the bottom of the card for actions. Accepts standard `div` props.

### CardAction

Slot in the top-right of `CardHeader` for contextual controls like buttons or menus.
