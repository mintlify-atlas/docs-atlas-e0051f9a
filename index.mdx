## Why Base UI?

Most component libraries mix multiple primitive systems — Radix UI, Vaul, Sonner, cmdk — each with its own portal and focus management. Composing them causes real bugs: Select inside a Drawer breaks focus, closing a toast dismisses the parent Drawer, Combobox portals render behind overlays.

Base UI uses **`@base-ui/react` exclusively**. Every overlay, floating element, and interactive primitive shares one system.

## Quick Start

<Steps>
  <Step title="Initialize your project">
    Run `init` to install dependencies, configure CSS variables, and create `lib/utils.ts`.

    ```bash
    npx baseui-cn init
    ```
  </Step>
  <Step title="Add components">
    Install individual components or everything at once.

    ```bash
    npx baseui-cn add button
    npx baseui-cn add dialog drawer toast
    npx baseui-cn add --all
    ```
  </Step>
  <Step title="Import and use">
    Components are copied directly into `components/ui/` — import them like any local file.

    ```tsx
    import { Button } from "@/components/ui/button"

    export default function Page() {
      return <Button variant="default">Get started</Button>
    }
    ```
  </Step>
  <Step title="Own the code">
    Every file lives in your project. Edit styles, rename exports, add variants — no library lock-in.
  </Step>
</Steps>
